# Lovable Plan Mode Pack

Use these files as context uploads in Lovable Plan Mode.

## Recommended upload order

1. `01-product-context.md`
2. `02-system-rules-and-constraints.md`
3. `03-ux-and-content-principles.md`
4. `04-current-signal-map-prototype-spec.md`
5. `05-plan-mode-master-prompt.md`

## Goal

Give Lovable enough context to propose plans that stay aligned with:

- your methodology (JTBD/ODI, positioning, strategy cascade, GTM execution)
- your evidence tiers (Public, Company, Evidence, Implemented & Tested)
- your scoring and signal behavior
- your current visual direction and interaction preferences

## Notes

- These files are written to be reusable across clients/markets.
- They avoid client-specific private details unless explicitly needed.
- `05-plan-mode-master-prompt.md` is copy/paste-ready.
