# UX And Content Principles

## Visual direction

- Clean, bright, white-forward UI.
- Background base: `#faf7f6`.
- Sans-serif for primary UI readability.
- Preserve existing house style and pill patterns.

## Communication style in product copy

- Plain, clear, human language.
- Avoid consulting buzzwords and jargon.
- Keep recommendations concrete and actionable.
- Preserve direct client quotes verbatim where appropriate.

## Interaction model

- Think GPS:
  - Zoomed out = overall route options and path context.
  - Zoomed in = next turn only.
- Prioritize “what to do next” over abstract totals.
- Use motion sparingly and meaningfully (slow pulse/movement, no noise).

## Explainability

- Every recommendation should indicate:
  - what evidence supports it
  - what is missing
  - why it matters
- Show confidence/provenance visibly.
- Differentiate overlap vs gap between public and company evidence.

## Data quality behaviors

- If data is pending, show pending clearly.
- If not assessed, show not assessed (not false gaps).
- If generated placeholders exist, label them explicitly.
